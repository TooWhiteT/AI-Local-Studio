# 《第三盏灯》试制性能记录

从 Studio 创建独立项目到最后一份选定成片任务成功结束经过 **34 分 28 秒**。这个区间包含编剧、审核等待、模型切换、配音及编码。计时在该导出成功时截止，随后进行的回放、校验和报告整理不延长制作历时。三集累计 180 秒。输入素材、试听 WAV、镜头视频和成片共核对了 167 个文件的 SHA-256。[逐任务输入哈希、引擎与尝试明细](../storage/m5-pilot/audit.json)

## 环境与测量方法

推理机报告 cuda:0 NVIDIA GeForce RTX 5090 : cudaMallocAsync，显存 31.82 GiB，可见系统内存 47.61 GiB。ComfyUI 0.46.0，PyTorch 2.12.0+cu130。语音引擎在工作台主机以 CPU 模式运行，初始音色 174 项，服务更新后实测 176 项。FFmpeg 使用 8.1.2。[现场环境快照](../storage/m5-pilot/environment.json)

SQLite 中的尝试记录提供排队、开始、结束和终态。执行耗时为租约占用时间，包括输入准备和结果确认。排队按每次尝试的入队到开工单独计算，同时提交多项任务时各任务的等待会叠加。显存和 RAM 表示推理机整体使用量的采样最大值。旁路每 3 秒观测工作台主机进程树及 ComfyUI。RSS 可能多次计入共享物理页。此项只统计工作台与 TTS 子进程树，独立运行的审片和语音识别工具没有计入。Windows 的 system_stats 显存采样可能漏计 llama.cpp，本表采用工作台调度器的资源采样值。CPU 配音和编码的占用见下文的进程树记录。[旁路原始样本](../storage/m5-pilot/resources.jsonl)
