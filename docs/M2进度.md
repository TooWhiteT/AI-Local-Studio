## 真机验收

验收使用 M1 故事《最后一张船票》第一集《违规的旧票》的 SQLite 备份和媒体副本。工作台监听 127.0.0.1:60871，调度 RTX 5090 上的 llama.cpp 模型 `studio-qwen` 和 ComfyUI 0.46.0，图片工作流为用户先前验证的 Z-Image-Turbo 1.0.0。原始 M1 数据库独立保存。

| 检查项 | 实际结果 |
| --- | --- |
| 剧本提取 | 从已审核剧本 V2 获取许棠、老周、候船室、旧票据、旧船票和纸条，保留场次来源 |
| 资产版本 | 实际生成许棠 V1 和 V2 两张不同的 1024 × 1024 图片。两份原图均通过 ComfyUI 输出、Studio 媒体接口、磁盘文件逐字节核对 |
| 固定引用 | 分镜 V1 共 3 镜、60 秒。选用角色 V2 后，回读该历史分镜的三个镜头，仍全都指向角色 V1 |
| 编辑与重做 | 调整一个镜头的时长和景别，反转镜头顺序，再让 Qwen 重做指定镜头。两条兄弟镜头的修订 ID 和顺序都与重做前一致 |
| 重启恢复 | 在 ComfyUI 已接受预览任务后重启 Studio，接回原尝试和 prompt ID。两次真机恢复用例均只有一次尝试 |
| SSE 和媒体 | 最终复测的预览任务从事件 137 回放至 145，共 9 条，包含采样节点 70 的进度和成功终态。重复使用同一幂等键返回同一任务。图片是 1024 × 1024 PNG，三处字节一致 |

## 回归验证

- `./gradlew test build --offline` 通过，37 项后端测试覆盖旧库迁移、任务恢复、审核冲突、未审核及跨项目引用、固定历史版本、无效模型输出及单镜头重做。
- `npm --prefix frontend run generate`、`npm --prefix frontend run build` 通过，客户端与 OpenAPI 契约一致。
- `STUDIO_BROWSER_CHANNEL=chrome npm --prefix frontend test` 通过，5 项 Chrome 端到端测试覆盖 M0 至 M2。分镜用例操作了候选对比、审核、修改、排序、单镜重做、预览、服务重启和窄屏布局。

真实模板接收文字提示词。工作台为每个镜头保留所选图像文件和版本，并把该版本的文字特征传入模板。角色外观一致性仍需人工审片。声音资产在此阶段保存为档案，声音合成属于 M4。
