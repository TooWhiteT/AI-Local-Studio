# M0 开发记录

开发范围为单用户本地图片生成。阶段验收记录在本文件，真实 GPU 冒烟单独记录。

| 子阶段 | 实施内容 | 验收方式 |
| --- | --- | --- |
| 1 工程与数据 | Gradle 模块、Vue 骨架、版本化迁移、项目创建与归档 | 构建两端，验证迁移重入、乐观锁和归档后查询 |
| 2 模板与适配器 | 导出包注册、绑定编辑、不可变版本、独立 Mock REST/WS 服务 | 模板校验、参数边界、HTTP 提交、WS 进度与 history 输出 |
| 3 任务与调度 | SQLite 队列、恢复、取消、重试、文件入库及 SSE | 模拟远端失败、响应丢失、重启和两个任务竞争，检查事件及文件哈希 |
| 4 工作台与联调 | 项目、资产生成、工作流编辑、任务中心，Ktor 托管 SPA | 前端构建和浏览器操作，端到端核对项目、任务、历史版本和媒体 |

初始目录仅有五份规范及其压缩包。工作台开发与构建运行于 macOS arm64，使用 JDK 21、Node 24。真实图片生成运行于局域网内的 Windows RTX 5090。

### 阶段 1

已运行 Gradle 多模块 `test build` 和前端 `npm run build`。4 项 JVM 测试通过，涵盖状态转换、DAG、SQLite 迁移重入、外键、分页、项目归档和乐观锁。

### 阶段 2

Gradle `test build` 和 Vue 生产构建通过。新增真实回环端口的 Mock REST/WS 集成测试，验证注册信息、未知节点、越界参数、请求注入、按 attempt 查询远端历史、WS 节点进度、PNG 下载和路径拒绝。

### 阶段 3

Gradle `test build` 通过，累计 12 项 JVM 测试。Mock 核实外部队列占用时提交数为 0，两个内部任务最大在途数为 1。运行中重启保留 prompt ID，丢失回执通过 attempt 对账，找不到回执的任务保持 UNKNOWN 并阻止新提交。失败、重试、依赖隔离、取消、不可变图片版本、SHA-256、SSE 游标及 reset、HTTP Range 和错误格式均已验证。前端骨架生产构建通过。

### 阶段 4

`npm run build` 通过类型检查和 Vite 打包。两项 Playwright 测试在本机 Chrome 通过。测试各自启动独立 JVM 运行 Mock 与工作台，使用临时 SQLite 和素材目录。桌面流程覆盖建项目、建资产、生成、浏览器刷新、重启后读取图片、失败后重试。390 像素手机视口覆盖发布新模板版本、编辑项目、归档与恢复。
