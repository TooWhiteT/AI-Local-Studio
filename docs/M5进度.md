# M5 三集试制 · 《第三盏灯》

## 制作范围

在正式工作台内新建独立试制项目《第三盏灯》。全剧讲述修灯匠林禾与守灯员许远在灯塔拆除前找回一面旧镜子的故事。第一集在旧修灯铺，第二集在暮色中的木栈桥，第三集在日出的灯塔灯室。每集剧本安排三个叙事段落，每段四个镜头，每镜五秒。制作中通过公开的工作台接口保存大纲、分集规划、剧本、资产审核、分镜和后期版本。

## 前期与镜头

Codex 编写三集剧本，通过工作台编辑和审核接口固化版本。真实 studio-qwen 完成三次资产提取和三次分镜规划。复核剧本后保存了 18 份场次人物状态，对照剧本校订了 6 处镜头动作，三集分别发布分镜 V3。Z-Image-Turbo 在 RTX 5090 上生成两张角色图和三张场景图。角色形象分别以齐耳短发、赭黄色工装与靛蓝围裙，以及短灰发、海军蓝外套与银灰色围巾识别。五份参考由 Codex 逐张查看并在试制项目中选用。[试制项目与分集记录](../storage/m5-pilot/preproduction.json) · [五份生成请求](../storage/m5-pilot/image-jobs.json)

每个镜头单独提交到持久化队列，使用已验证的 H3 R2V 工作流、已审核的参考图、独立种子和五秒目标时长。调度和资源采样复用 M3 的单 GPU 租约。配音通过 Studio 的 CPU 语音服务入队，按剧本对白逐镜生成。在视频审核后再建立对应时间线和导出。当前工作台数据和原始媒体均保存在本机。
